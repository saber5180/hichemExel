  📋 WORKFLOW DÉTAILLÉ
═══════════════════════════════════════════════════════════════════════════

ÉTAPE 1: UPLOAD
───────────────
http://localhost:3001/upload

- Upload votre fichier Excel (.xlsx, .xlsm)
- Les données vont dans SHEET1 (pas ALERTE)
- SOLDE calculé automatiquement (I - J)

ÉTAPE 2: SHEET1
───────────────
http://localhost:3001/sheet1

- Voir toutes les données importées
- Bouton "Synchroniser" = Tout envoyer vers ALERTE
- Ou utiliser AJOUT DR pour sélection individuelle

ÉTAPE 3: AJOUT DR
─────────────────
http://localhost:3001/ajout-dr

1. Taper N° Facture (ex: FC26SOP219879)
2. Cliquer "Chercher"
3. Système cherche dans Sheet1
4. Remplir Nature Dérogation + Dates
5. Deux options:
   - "Ajouter au Tableau" = Tableau d'attente
   - "Transférer Direct" = Vers destination finale

ÉTAPE 4: TRANSFERT
──────────────────
Depuis n'importe quelle page:
- Menu déroulant "Transférer..."
- Choisir destination
- Facture change de statut
